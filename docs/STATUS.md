# 实现状态

日期：2026-11-23（北京时间）。对照的是已批准的设计 v0.1。下面只记录这轮代码，不改设计原文。

这是可编译、可测试的第一段，不是 12 月 1 日前的完整软件，也不是各平台稳定版。

## 这轮写了什么

- 控制面：SQLite、Argon2id、15 分钟访问令牌、刷新令牌轮换、重用即作废整族、设备密钥登记、指纹确认、授权、撤销、审计哈希链、制品 SHA256 与单独的更新签名密钥。
- 13111：HTTPS、管理 API、中文 Vue 管理页。内部票据接口在 13112，公开端口上返回 404。没有执行命令或构建命令的接口。
- 13110：TCP 网关。没有票据不能中继。中继字节是 Noise_IK 密文。直连 TCP 与中继同时启动，用探测往返而不是第一次 TCP 完成来选路。
- Linux 图形探针：Xvfb 上的真实窗口，x11grab 采集，libx264 编解码，只观看时不调用 xdotool，允许控制时点击会改变窗口颜色。
- 客户端命令：设置服务器、固定指纹、用文件中的密码初始化管理员、登录、登记、批准。

网关用 Go 写成，和客户端共用同一套协议代码。设计里的默认是 Rust。这是记录在案的偏差，不是把 Rust 网关从目标里去掉。

## 已测试

在这台 Linux 上 `go test ./...` 通过，包括：

- 账号、错误密码、刷新重用、设备批准、无人值守票据、票据不能用两次、私有下载、签名被改掉后验证失败
- 证书指纹不符时客户端拒绝连接
- 网关拒绝无票据连接，并转发密文
- 中继人为延迟后，选路选中更快的直连，H.264 帧经选中的路径解码后仍是红色
- UDP cookie 请求和响应一样长
- Xvfb 采集、只观看拒绝输入、控制点击变色

命令行也对着本机 `127.0.0.1:13141` 跑过一遍初始化、登录、登记和批准。控制日志里没有引导凭据、内部令牌或密码。

## 没有做

- RustDesk 源码没有拉入仓库，也没有链接。当前图形路径是 ffmpeg / X11，不是 RustDesk 引擎。
- ALVR、SteamVR、头显、姿态和手柄都没有。
- Windows 7/10/11、macOS、Android、Pico、iOS、iPadOS、visionOS 都没有构建或真机测试。
- 操作系统虚拟显示器（L3）没有。L1 只有裁剪矩形的坐标函数。L2 只在 Xvfb 上枚举到一块屏幕。
- 网关还没有听 UDP。13110/UDP 的打洞 cookie 只在测试里的两个本机套接字之间验证过。
- 没有把 CLI 的 `agent` / `connect` 做成可长期观看的桌面会话命令。库函数已经能传一帧真实图像。
- 没有硬件编码器探测，没有画质预设的实机测量，没有音频进会话（只单独测了 Opus 编码）。
- 没有 Apple 签名、公证或 Win7 工具链。
- 这台机器没有 Docker，Compose 安装没有实际跑过。
- 没有公网部署，没有购买，没有使用任何真实账号。
