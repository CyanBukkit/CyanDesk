## 0.1.5 直连 UDP 头部

0.1.5 的直连 UDP 在 Noise IK 握手之后，把 13 字节头部放在 ChaCha20-Poly1305 密文外面，没有作为 AEAD 关联数据。

密文本身仍由认证标签保护。只改 nonce 字段再拿去解密，标签对不上，不能由此伪造输入或解开画面。

代数字段在校验标签之前就被用来决定是否换钥。把代数字段改成“当前代 + 1”并附上任意密文时，接收方会先换掉这一方向的接收密钥，随后解密失败。这一方向的直连 UDP 会失去同步，直到新的握手。这不是读画面或注入点击的路径。中继 TCP 不使用这个数据报头部。

因此不能把 0.1.5 的直连 UDP 写成“因为加密过所以头部也安全”。对正在进行的私人测试，没有发现必须中断测试的机密性或输入伪造问题。能向直连端口注入 UDP 的人可以打掉这条直连。内部源码已改为头部进入关联数据，并且只有解密成功才换钥；该改动不在 0.1.5 包里。
