# 网关语言：暂用 Go，等待用户接受

状态：提议，尚未被用户接受。这不是对已批准设计的静默修改。

批准的设计把信令/中继网关写成 Rust。当前仓库里的 13110 网关是 Go，和客户端使用同一套帧格式与 `github.com/flynn/noise`。

## 为什么这轮没有重写

持续桌面会话要接在已经测过的票据、Noise 和路径选择上。把同一协议再实现一遍会挤掉主机采集、权限和重连。功能对齐之后再换语言，测试向量可以留着。

## 影响

- 安全：票据仍由控制面核销，中继看不到明文。密码库是现成的 Noise 实现，不是自造算法。Go 的内存安全和 Rust 不一样，网关进程被攻破时的后果不同。这一点没有在这轮做对照试验。
- 性能：没有做 Go 与 Rust 的吞吐或延迟对照。本机测试只说明功能，不说明生产中继容量。
- 行为：一端断开时网关会关掉另一端。这是这轮补上的，避免主机在对端离开后一直占着会话。

如果要改回 Rust，应单独做一次替换，并用现有的网关测试和桌面会话测试验收，而不是在这一轮里只留下一个不能跑的 Rust 空壳。
